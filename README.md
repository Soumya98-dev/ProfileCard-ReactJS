# ProfileCard-ReactJS

![alt text](image.png)

A simple React app that displays a personal profile card.

## Features

- Responsive profile card built with **React** and **CSS**.
- Profile photo, bio, and color-coded skill badges.
- Clean typography and subtle shadow/rounded styling.

## Quick Start

```bash
# clone the repo
git clone https://github.com/Soumya98-dev/ProfileCard-ReactJS.git
cd profile-card

# install dependencies
npm install

# start the dev server
npm start
```
